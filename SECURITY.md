# Security Policy

## Supported Versions

Currently, only the latest release of WheelEye is supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within WheelEye, please DO NOT open a public issue. Instead, send an e-mail to the maintainers directly. All security vulnerabilities will be promptly addressed.

We will provide an initial response to your report within 48 hours. If the vulnerability is accepted, we will work with you to draft a timeline for the fix and a public disclosure plan.
